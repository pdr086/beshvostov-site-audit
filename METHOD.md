# Как проводилась проверка

**Дата аудита — 26.04.2026.**

Точкой входа была главная. Обход охватывал адреса из HTML-ссылок, карту сайта, подключённые стили, скрипты, изображения и шрифты, а также варианты главного адреса и один контрольный отсутствующий путь. При открытии Telegram проверялась только общедоступная страница назначения. Заявки, платежи и сообщения в канал не отправлялись.

## Что и как перепроверить

| Проверка | Процедура |
|---|---|
| Инвентарь | Загрузить главную и обе страницы из подвала. Сопоставить title, description, H1, lang, canonical, robots, JSON-LD и цели ссылок. Сверить фрагменты ссылок с id конечных документов |
| Доставка | Для адресов страниц и ресурсов сделать обычный GET с поддержкой сжатия и сохранением цепочки ответов. Размеры `received_bytes` и `decoded_bytes` относятся к телу ответа до и после распаковки. `set_cookie` обозначает присутствие заголовка в конечном ответе |
| Направления | В окне 390 × 844 выбрать каждую вкладку, сравнить выбранный tab, открытую панель, подпись и блок цены. Сверить восемь пар «позиция — цена» по всем шести блокам. Проверить прямой URL, обновление и неизвестное значение |
| Навигация | На трёх страницах проверить первый Tab и Enter. На главной использовать Home, Enter, стрелку вправо и пробел. Перебрать стрелки персонажа. Клавишей Enter открыть и закрыть каталог и все шесть вопросов |
| JavaScript выключен | В новом контексте отключить JS и открыть `/?direction=it`. Проверить видимое название тарифа, раскрыть каталог направлений, найти ссылку записи |
| Макет | Открыть главную в Chromium на ширинах 320, 390, 768 и 1440 CSS px. Сопоставить scrollWidth и innerWidth. Позицию CTA и прайса измерять от начала документа. На трёх ширинах сохранить снимки и визуально проверить последовательность блоков |
| Автоматическая доступность | Chromium 148.0.7778.96, axe-core 4.10.3, ширина 390 px. Проверить три документа в начальном состоянии после перехода по skip-ссылке. Набор тегов axe — wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22aa. Incomplete требует отдельной оценки |
| Скорость | Playwright 1.60.0, Chromium 148.0.7778.96, новый контекст для каждого из трёх прогонов, HTTP-кеш отключён. Размер окна 390 × 844, загрузка 200 000 Б/с, отдача 93 750 Б/с, задержка 150 мс, замедление CPU ×4. Получить PerformanceNavigationTiming, ResourceTiming, paint, largest-contentful-paint и сумму layout-shift без недавнего ввода до конца короткого окна наблюдения после загрузки |
| Приватность | В чистом контексте до ухода в Telegram проверить перечень хостов ресурсов, cookies контекста, localStorage и sessionStorage. В HTML отдельно посчитать формы |

Дополнительный прогон в WebKit 26.4 и Chromium повторял выбор IT при 390 × 844 с включённым уменьшением движения, затем открывал документы. Для девяти текстовых элементов в Chromium зафиксировали вычисленный цвет шрифта, временно сделали текст прозрачным и взяли точки видимого фона из прямоугольников строк с шагом 2 px. По относительной яркости каждой пары цветов рассчитали минимальное и максимальное отношение контраста. Результаты применимы к проверенному состоянию.

Для быстрой повторной проверки открыть главную в адаптивном режиме DevTools при 390 × 844, перейти на IT и прокрутить к цене. Отдельно открыть обе страницы из подвала и внешний Telegram-переход. При оценке производительности использовать холодный кеш и сопоставимый профиль сети. Цифры зависят от устройства, сети, версии страницы и браузера.

## Границы выводов

Три страницы — число уникальных документов, обнаруженных по публичной навигации и карте. Варианты имён хоста, `index.html` и параметры выбора учтены отдельно. Ширины телефонов эмулировались. Оригиналы снимков показывают посетительский интерфейс с тестового сеанса.

Измерения производительности лабораторные. Запрос к публичному PageSpeed Insights API получил HTTP 429 из-за квоты. Данные реальных пользователей CrUX, INP, поисковые показы, индексация в кабинетах Google и Яндекса, посещаемость, число заявок и выручка остаются неизвестными. Связь между улучшением интерфейса и ростом заказов — проверяемая гипотеза.

Проверка транспорта опирается на обычные запросы посетителя. Внутренняя инфраструктура, исходный репозиторий, резервные копии, права доступа, журналы и внутренние процессы исполнителя требуют отдельных данных. Наблюдения о документах описывают их содержание на дату проверки. Соответствие деятельности правовым требованиям и качество самих консультаций отдельно не оценивались.
